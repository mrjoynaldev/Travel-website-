# SKILL: Lead Generation for Sundarban Yatri

The site exists for ONE commercial reason: turn Sundarban trip planners into
phone calls, WhatsApp chats and `/hire` enquiries. Content, tours, reviews and
social all serve that funnel. Read this before writing, publishing or
reordering anything.

Companions: `SUNDARBAN-FACTS.md` (ground truth) · `TOUR-SKILL.md` (products) ·
`SHOWCASE-SKILL.md` (proof) · `SOCIAL-SKILL.md` (distribution).

---

## 1. Who we sell to (know them cold)

| Segment | Who | What they worry about | What converts them |
|---|---|---|---|
| Kolkata families | 3–8 people, weekend + holidays, budget-aware | Safety, food, toilets, kids, "is 1 day enough?" | Clear inclusions, veg food proof, easy call CTA |
| Couples | 2 people, Oct–Feb, experience-led | Privacy, stay quality, sunset points | 2D/1N imagery, food + stay photos |
| Photographers / birders | Small groups, winter migrants Nov–Feb | Safari odds honesty, watchtowers, timing | Honest odds, Dobanki canopy, early starts |
| International travellers | Solo/pairs, plan months ahead | Permits, how to reach, payment, language | `/hire` form, detailed email-ready answers |

Everyone shares one anxiety: **"Will this trip actually happen smoothly in a
remote mangrove forest?"** Every page must answer that with specifics, not
adjectives.

## 2. The funnel (every page has a job)

```
Search / social
  → Guide (answers the trip question, earns trust)
    → Tour page (concrete plan + price note + gallery)
      → Call / WhatsApp  ← PRIMARY, always one tap away
      → /hire enquiry form ← SECONDARY, for international / after-hours
        → Studio lead (new → contacted → won / lost)
```

Rules:
1. **Call/WhatsApp first, form second.** Indian travellers call; never present
   the form as the primary CTA to a domestic audience.
2. Every guide ends with a call/WhatsApp CTA **and** links ≥1 tour. A guide
   with no commercial next step is a leak — fix it.
3. Sticky mobile CTA (WhatsApp · Call · Quote) must survive every redesign.
4. Never invent urgency ("only 2 seats left") or discounts. Real seasonality
   (winter rush, festival dates) is the only urgency you may state.

## 3. Seasonality calendar (plan content + capacity around it)

- **Peak (Oct–Mar):** pleasant weather, winter migrants Nov–Feb, highest
  demand around Christmas/New Year and weekends. Publish cost/itinerary guides
  Sep–Oct to catch planners. Weekend tours sell out — say so honestly.
- **Shoulder (Apr–May):** hot, fewer crowds, possible deals. Good for
  photographers who tolerate heat; say plainly it is hot.
- **Monsoon (Jun–Sep):** heavy rain; many forest operations pause or run
  limited. Hilsa-festival interest spikes mid-monsoon. Never promise a normal
  safari in peak monsoon — check the current season's actual running status
  with the owner before publishing anything seasonal.
- **Always verify** festival dates, forest entry rules and running status with
  the owner each season. Last year's facts are not this year's facts.

## 4. The lead pipeline (Studio → Leads)

Statuses: `new` → `contacted` → `won` / `lost`. Work it like this:

1. **Speed wins.** Contact every `new` lead the same day, ideally within hours.
   Travellers message 3–4 operators; the first real reply usually wins.
2. **Reply with specifics, not brochures.** Reference their date, group size
   and tour. Quote the honest inclusions. Name the meeting point and time.
3. **Move the status the same day** you act: `contacted` after first real
   reply, `won` on confirmed booking with date, `lost` with a one-line reason
   (date passed, chose elsewhere, no reply in 7 days).
4. **Lost ≠ dead.** Festival-season broadcast (WhatsApp) to old `lost`/`contacted`
   leads converts every year. Keep the data clean so it stays usable.
5. **Never share lead data** outside follow-up. No screenshots with phone
   numbers in reviews or social posts.

### First-reply WhatsApp script (adapt, don't copy-paste blindly)

> Namaskar {name}! Sundarban Yatri here — thanks for your enquiry about the
> {tour} on {date} for {n} people. Yes, we are running that weekend. Meeting
> point is {place} at {time}; {1 line on stay/food}. Shall I hold {n} seats
> while you confirm? — {owner name}

Short, specific, ends with a yes/no question. Second message only if they
reply. No "Dear Sir/Madam", no 6-paragraph itineraries unasked.

## 5. CTA placement checklist (audit every new page)

- [ ] Phone number tappable (`tel:`) above the fold on mobile
- [ ] WhatsApp deep link carries context (tour name / page topic prefilled)
- [ ] Tour pages: sticky enquiry card on desktop, sticky bottom bar on mobile
- [ ] Guides: mid-article tour link + end-of-article call/WhatsApp block
- [ ] Forms ask the minimum: name, phone, date, travellers, message — nothing more
- [ ] Success state offers "Continue on WhatsApp" (never a dead end)

## 6. KPIs (review weekly in Studio)

- **Enquiries:** leads created/week, share by source page (which guides convert?)
- **Speed:** median hours from `new` → `contacted` (target: same day)
- **Win rate:** `won` / (`won` + `lost`) per month, per tour
- **CTA health:** clicks on call/WhatsApp (analytics events) per top page
- **Proof stock:** published video reviews + menu photos added per month
  (social proof compounds — see `SHOWCASE-SKILL.md`)

If a guide gets traffic but zero enquiries for 30 days, its CTA or tour link
is broken — fix the commercial path before writing new content.
