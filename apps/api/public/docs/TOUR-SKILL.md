# SKILL: Tour Products for Sundarban Yatri

Four products, no more until demand forces it: **1-day · 2 days/1 night ·
3 days/2 nights · Custom**. Manage them in Studio → Travel catalogue → Tours.
Every field you set is a promise a traveller will hold you to.

Companions: `LEAD-SKILL.md` (funnel) · `SUNDARBAN-FACTS.md` (ground truth).

---

## 1. The four products (what each is FOR)

| Tour | For | Shape |
|---|---|---|
| 1 Day | Kolkata weekenders, tight schedule | Dawn departure, creek cruise, Sajnekhali tower, village walk, back by evening |
| 2D / 1N | The default choice — couples, families | Safari + Dobanki canopy walk + riverside stay, unhurried |
| 3D / 2N | Birders, photographers, slow travellers | Deep beats: Jharkhali, Gosaba, extra cruise hours |
| Custom | Groups, photographers, special needs | Private itinerary built around their brief |

Position 2D/1N as the default recommendation. 1-day is honest about what it
skips (no deep forest, early start, long day). Custom exists to catch every
"we are 14 people / we only want birds" enquiry — never turn those away.

## 2. Itinerary honesty (the whole brand in one section)

- **Realistic timings only.** Boat speed, tide windows, forest entry slots and
  lunch halts are fixed constraints. If Day 1 says "reach Sajnekhali by 9:30",
  that must be the actual plan, verified with the boat crew this season.
- **Name real places** (Godkhali jetty, Sajnekhali, Dobanki, Jharkhali,
  Gosaba, Pakhiralay) — never "a beautiful watchtower".
- **State what is NOT included** as clearly as what is. Exclusions prevent
  the #1 source of bad trips: expectation mismatch.
- **Safari odds, honestly:** tigers are wild and elusive; deer, boar, crocs
  and birds are common. Say exactly that. Never imply guaranteed sightings —
  one disappointed review costs more than ten bookings.
- **Meeting point + time + transport + stay** must be filled on every tour.
  "We will inform later" is not a product.

## 3. Pricing without lies

- Show a price **only** if the business can keep it current. Otherwise use a
  price *note* ("Winter weekend rates", "Festival dates") + "Get a Quote".
- Never show strikethrough "discounts" that were never real prices.
- Cost drivers to explain in guides (not fake totals): group size, boat
  sharing vs private, stay category, season, permits/entry fees.

## 4. Gallery standards

- Cover: one strong real photo (boat on creek / mangrove channel / sunrise).
  No generic beaches, mountains, or foreign stock.
- Gallery: 4–8 photos covering boat, food, stay, watchtower, village. Upload
  in Studio (tap-to-upload) — never hotlink random web images.
- Every gallery photo should answer "what will I actually see/do?".

## 5. Seasonal operations

- Before peak season, re-verify every tour: timings, stay partner, boat,
  price notes. Update `updated_at` by saving — travellers (and Google) trust
  fresh pages.
- Monsoon: mark honestly which tours run limited or pause; push Custom + next-season advance enquiries instead of forcing sales.
- Festival specials (winter fair, hilsa season): create the dated variant as
  its own entry or price note — never silently change the base tour.

## 6. Tour page QA (before publishing)

- [ ] Title, duration, days, category, summary all filled
- [ ] Overview answers: who is this tour for + what will the days feel like
- [ ] Itinerary day-by-day with real place names and meal notes
- [ ] Inclusions AND exclusions filled
- [ ] Meeting point, transport, stay, best-for filled
- [ ] Cover + ≥4 gallery photos, all real
- [ ] Price note current (or removed) — no stale numbers
- [ ] Related guides linked; enquiry card + sticky mobile CTA present
