# SKILL: Travel-First Distribution (social that books trips)

For Sundarban Yatri, social media is a **trip-intent machine**, not a traffic
game. Priority order is fixed: visual proof first, links second, syndication
last. Every placement must end at a tour, a guide, or WhatsApp — never at
vanity metrics.

Companions: `SHOWCASE-SKILL.md` (raw material) · `LEAD-SKILL.md` (funnel).

---

## 1. Channel priority (do not invert)

| # | Channel | Job | Format |
|---|---|---|---|
| 1 | **Instagram** | Reels from real review clips + food + sunrise cruises; bio link → tours | 1080×1350, captions NOT clickable → "Link in bio / DM us" |
| 2 | **Facebook Page** | Same visuals + tour links (links ARE clickable, OG preview) | Link on its own line + 1 strong cover |
| 3 | **YouTube** | 30–60s review clips + safari snippets; description links | Shorts + one 3-min "what a 2D/1N feels like" |
| 4 | **WhatsApp** | Broadcast to past + lost leads at season start; status clips | Short, personal, one CTA |
| 5 | **Reddit / Quora** | Answer real trip questions (r/travel, r/india, Kolkata subs; Quora Sundarban topics) | Value-first answer, link only where it completes the answer |
| 6 | Bluesky / Mastodon | Link drops, same-day OK | Short + hashtags, full URL |
| 7 | dev.to / Medium | SEO syndication of guides ONLY, 7–10 days after publish, canonical to us | Teaser, never full copy |

Channels 1–4 book trips. Channels 5–7 build reach. Spend time in that ratio.

## 2. The content loop (one trip → a week of posts)

Every operating tour should yield: 1 review clip + 2 food photos + 1 sunrise/
cruise photo. From that raw material:
- Day 1: Reel (review clip) + FB post with tour link
- Day 3: Food photo carousel ("what lunch looks like on the boat")
- Day 5: Guide link drop answering the question the clip raises
- Weekend: WhatsApp status + broadcast nudge for unsold weekend seats

No raw material = no posting. Never post generic travel quotes or stock.

## 3. Mechanics that matter (platform truth)

- **Instagram captions are not clickable.** Always "Link in bio" or "DM
  'GUIDE'". The Comment→DM automation in Studio exists for exactly this.
- **Facebook links preview** from OG tags — keep `og-default.png` and per-post
  OG images real (1200×630).
- **Reddit/Quora punish link-dropping.** Answer fully in the reply; the link
  is a footnote, and only to the exact guide that continues the answer.
- **Full-copy syndication waits 7–10 days** after publish; canonical URL
  always points to us. Teaser-only before that.

## 4. Comment→DM automation (Instagram)

Studio → Automations: keyword (e.g. GUIDE, SAFARI, COST) on a reel → instant
DM with the guide link + follow gate. Rules:
- One automation per active campaign post; pause when the season ends.
- DM template: greeting + exact link + one-line next step ("Reply DATE and
  I'll check seats"). No paragraphs.
- Review automation logs weekly; dead keywords get replaced, not stacked.

## 5. Weekly distribution ritual (30 min)

1. Publish guide/tour update → run the distribution kit → approve queue.
2. Cut 1 reel from the newest review clip; schedule FB twin.
3. Answer 3 real trip questions (Reddit/Quora) with value-first replies.
4. Check automation logs + lead sources: which post brought enquiries?
5. Log what worked in one line for next week's plan.

If a channel brings zero enquiries for a month, cut its time — not the
reel habit. Proof compounds; platforms don't.
