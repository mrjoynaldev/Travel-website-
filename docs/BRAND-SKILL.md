# SKILL: Brand Kit — Hero, Trust, Safari, About

The brand kit (Studio → Brand) controls everything a first-time visitor
absorbs in 10 seconds: the hero background, the trust badges, the safari
block and the about photo. It is the highest-leverage screen in the Studio —
small changes here move enquiries more than any new guide.

Companions: `LEAD-SKILL.md` (why first impressions convert) ·
`SHOWCASE-SKILL.md` (where hero/review media comes from).

---

## 1. Homepage hero (image or video loop)

- **Image mode (default):** one wide, real photo — dawn over a creek, boat in
  mangroves, watchtower against sky. Landscape, uncluttered on the left where
  the headline sits. No text baked into the image, no generic beaches.
- **Video mode:** 5–15 second loop, MP4/WebM ≤50 MB — slow creek glide,
  sunrise timelapse, riverside life.
- **Copy:** eyebrow (5–7 words) → headline (one promise, ≤12 words) →
  subheading (one sentence: waterways + wildlife + villages + tours). Name a
  real thing in every line. If a field is left empty, the site keeps its
  default — blank never breaks the layout.
- Change the hero **at most once a season**. Travellers returning from a
  half-planned trip should recognize the site.

## 2. Trust badges ("Why choose us", max 6)

- Each badge = one verifiable truth: local guidance, realistic itineraries,
  human replies, planning help. If you can't prove it on a call, don't badge it.
- Keep 4. Add a 5th/6th only for a second proven strength (e.g. licensed
  fleet, festival specials). Order = persuasion order; best proof first.
- Icons are symbolic, never literal claims — a compass doesn't promise tigers.

## 3. Safari feature block

- Photo: real safari moment (creek, watchtower, guide at work). Refresh yearly.
- Heading + intro: what a safari IS here (boat-based beats + towers) in two
  breaths. Checklist: 3–4 items max — permits handled, boat comfort, honest
  odds. Re-verify the copy every season (rules and timings drift).
- This block feeds the #1 high-value enquiry (photographers/birders) — keep
  it honest and specific, not poetic.

## 4. About page photo + identity fields

- About photo: the team/boat at work, daylight, real faces welcome. This is
  the "humans behind the site" moment — stock ruins it instantly.
- Website name, tagline, description flow into the header, footer, SEO titles
  and social cards. Change the name only with the owner — it echoes across
  Google, sitemaps and feeds.
- Logo/favicon/social image: upload-only, no pasted URLs. SVG logos must be
  script-free (the uploader rejects executable SVGs).

## 5. Brand QA (before and after every change)

- [ ] Desktop + one real phone: hero readable, headline not covered, video plays muted
- [ ] Empty fields intended? Confirm fallbacks look right
- [ ] No stale seasonal copy (festival dates, "this winter" in July)
- [ ] Colors pass contrast on buttons and badges
- [ ] OG/social preview re-checked after logo/cover swaps

Brand changes are instantly public and audited. Preview on the live homepage
right after saving — the brand kit has no draft mode.
